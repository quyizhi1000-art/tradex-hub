# 双拐雷达 v2

> 已于 2026-09-18 停用：放宽为“当前金叉状态”不符合需求。当前恢复 v1 当天新金叉条件；盘中仍按上一交易日 v1 存档取差集，开盘第一轮符合的股票也算新增。v2 记录仅保留核对，不作为当前选股或收盘确认。以下是当时的实现记录。

2026-09-18 起，盘后 MACD＋J 选股使用 `macd-j-upturn-main-board.v2`：

- 当前 DIF > DEA；不再要求前一交易日 DIF ≤ DEA。
- 当前 J 高于前一交易日；最近一次 J 向上拐头发生在当天或此前 1～3 个交易日。
- 主板、非 ST、成交、历史完整性与指标口径检查保持原有要求。低位只做标签。
- J 拐头超过窗口会退出当前股票池；退出不等于趋势反转。

盘中继续使用实时日线推算，并保留 DIF−DEA > 0.004、J 增量 > 0.02 的舍入保护。盘后使用正式发布指标，临界值可能不同。

盘中每轮展示集合为：**本轮当前符合条件的股票 − 上一交易日同版本盘后存档股票**。同一天各轮使用同一基准，不减上一轮结果。当日早些时候已出现的新增股，本轮仍符合条件就继续展示；每只股票的提示仍按日去重。

`intraday_increment.with_previous_close_difference` 是只读展示投影，同时服务实时接口、扫描记录和提示。Collector 仍独占扫描刷新与原始记录写入。原始扫描保存完整候选池与 `screen_version`；展示结果的 `comparison` 保存基准日期、结果 ID、证据修订、原始命中数、剔除数与新增数。

只读取准确的上一交易日 v2 存档；缺失、不可用或日历未核验时返回 `baseline_unavailable`，不把全部候选误报为新增。基准覆盖不足时明确提示：新增仅表示相对已存档名单的差集。盘后收盘确认仍展示同日正式完整股票池。

v1 存档及既有扫描不改写，界面标注“当天新金叉”旧规则。v2 使用既有不可变策略存档表，无新增数据库或调度器。未来盘后生成由现有 Analysis Worker 执行 v2。

切换时以已留存的真实历史日线、指标和对应日期 ST 名单补算 2026-09-17 基准，实际生成时间为 2026-09-18；没有使用 9 月 18 日行情反填昨日指标。
