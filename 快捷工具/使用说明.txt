tradex 本地快捷工具
===================

双击对应的 .cmd 文件即可：

1. 启动网页看板.cmd
   启动 http://127.0.0.1:8765/ 并自动打开浏览器。

2. 停止网页看板.cmd
   仅停止由本工具启动的网页看板，不会误杀其他 Python 进程。

3. 启动MCP服务.cmd
   启动本地 HTTP/SSE MCP 服务，连接地址：
   http://127.0.0.1:8000/sse

4. 停止MCP服务.cmd
   仅停止由本工具启动的 MCP 服务。

5. 一键全部启动.cmd / 一键全部停止.cmd
   同时管理网页看板和 MCP 服务。

6. 查看运行状态.cmd
   显示两个进程的端口和 PID。

运行日志和进程状态保存在项目根目录的 .tradex-run 文件夹中。
该目录是运行时临时数据，不需要手工修改。
