# 聪明板块库：股票市场归属判定方法

状态：2026-09-19 首轮全目录逐股审阅及发布完成；方法与证据按日期保留。本文是项目长期规则，后续任务与上下文压缩后必须先读。

## 2026-09-19用户纠正：完成审阅必须给出唯一归属

每只完成审阅的股票都必须从该股已有行业或概念中选出一个明确主归属。多个真实业务并存、缺少量化主线强弱数据，不能作为不作判断的理由。优先选择有真实业务支持且市场识别清晰的概念；新增题材关键证据不足时，分析员应结合完整材料选择证据最充分的现有行业或概念，并说明取舍，而不是由程序自动复制供应商首项或最大收入行业。

新项目、控制关系、商业化阶段等疑点写入依据和后续复核条件，不能让局部疑点否定已经证实的经营归属。确实缺少可读材料时继续补证，该股票属于尚未完成审阅，不得以“无法明确归属”作为完成结论。批次发布必须拒绝没有唯一主归属的审阅记录。未审阅数量与已完成归属数量分开展示；真实证据失效、过期或结论本身冲突仍须复核，不伪造核验完成。

## 2026-09-19用户纠正：只能从该股已有板块中选择

主归属必须对应这只股票已有的行业板块或概念板块，不能按业务描述创造新的分类或产业层级。业务、市场认知和证据核验用于在已有候选中判定主次，而不是生成新板块名称。例如三花智控和中大力德都使用已有“人形机器人”；执行器、减速器分别放入产业链说明，不能代替主板块。

每条明确归属的审阅记录必须留存来源板块原名和发布方，核对该名称确实存在于该股票保存的概念列表或行业/概念成员列表。名称只可去除“概念”后缀或行业分级标记Ⅱ/Ⅲ等不改变含义的格式部分；不得将若干行业概括成自造的“医药制造”“农产品流通”等板块，不得只因业务文段提及某产品就宣称已有对应板块。来源候选中的地域、指数、持股及风格标签仍不自动成为产业主归属。

发布时还须显式填写实际业务阶段，禁止默认为已产生收入。临床试验记录为pilot并注明临床含义，具体产品或商业化准备但未证实交付记录为product，订单、交付、收入分别需要对应证据。理由写“尚未销售”而结构化字段填写revenue属于矛盾，必须在入库前纠正。

用户举例是方法校准，不能代替具体来源核验。若示例板块尚未在当前保存材料中检出，应说明资料范围和缺口；不能伪造成员关系，也不能因此声称其他数据源或日期一定不存在该关系。已有结果中违反这一规则的自建名称必须重新对应，并保留更正前快照供追溯。未完成该项核对的批次不得发布。

## 要解决的问题

股票市场归属回答：市场将这只股票作为哪条产业主线、哪一环节的标的交易，而且该关系有真实业务支撑。它不是主营收入最大项、申万行业、供应商概念标签集合，也不等于某一天上涨的原因。

市场可能围绕未来业务增量定价。不能因新业务收入占比较小就排除其市场主归属；也不能凭热点名词、参股、规划、传闻或短期相关性认定主归属。

## 分析步骤与证据要求

1. 汇集候选：读取供应商概念成员、概念解析、市场题材报道与已有归属记录。保留来源与日期，不按列表位置确定主次。
2. 验证产业链位置：核对公司公告、定期报告、产品、客户合作、订单、交付等证据，说明公司到底提供什么产品或服务、位于产业链哪个环节。
3. 验证市场认知：结合近期可追溯的题材事件、多个来源及持续性，判断主线与次要标签。概念成员只能证明被列入；统计联动只能提供佐证，不能独立证明因果。
4. 综合判断：有真实产品/业务、市场认知支持的增量方向可以成为主归属，不机械按营收排序。仅投资关联、计划、传闻不得自动升级为主归属。
5. 记录结果：市场主归属、产业链细分、其他业务/概念标签、主营背景、证据日期与链接、复核日期、判断理由和待核验事项分别保存。
6. 管理变化：市场归属允许随业务和主线变化更新。历史记录保留当时版本；后来的证据不得反向改写历史判断。日级行情归因是另一种结果，不能用长期归属冒充当日涨跌原因。
7. 完成审阅必须选定一个有依据的现有主归属；局部疑点另列复核条件。材料缺失导致无法审阅时继续补证，证据过期或结论本身冲突时进入复核，不伪造贴合度分数或同向行情验证。

用户已确认的证据标准：同花顺解析与另一发布方的公司业务资料逐项交叉核对，记录为 `crosschecked_sources`；有冲突或关键疑点再查原公告，完成后记录为 `official_disclosure`。仅有同花顺概念名称、多个网站转载同一概念名单，均不能满足业务核验。参股与控股经营、规划与已交付、下游用途与供应链订单等关键疑点须回原公告；未解决的题材不能凭空确认为主归属，应依据已证实经营在其他已有候选中作出判断，并保留该题材的复核事项。

## 项目实施边界

- 聪明板块库是股票市场归属的唯一读取和判定入口。页面、分析任务、选股、MCP不得各自维护映射、按关键词取第一个板块、用供应商行业顶替市场归属。
- 现有证券关系目录继续保存主营、统计行业、原始概念与业务证据，作为聪明板块库的输入；这些字段不能被市场归属覆盖。
- 板块指数本身的行情、资金流和统计行业同业比较有独立语义；统一股票市场归属不能静默更改这些数据口径。
- 复用现有采集/分析进程、共享服务与本地目录。网页请求只读，不在打开页面时联网分析或逐股抓取。
- 主页提供“聪明板块库”入口，二级界面能按板块/概念浏览对应股票，也能按股票查归属、细分、证据和状态；待核验及未覆盖不可隐藏。
- 历史选股档案、当日涨停池及其他修订绑定结果必须保留原始日期/版本，当前归属更新不能伪装成历史时点已知信息。

## 已确认的产品选择

- 每只股票只发布一个市场主归属；普通页面及分析只展示该主归属。标签和产业链细分放在聪明板块库或明确指定的详情。
- 统一所有股票市场归属的读取，板块行情与资金流来源保持原有口径。
- 每只完成审阅的股票必须有唯一明确主归属；尚未分析的股票显示“尚未审阅”，禁止自动复制供应商标签补位。此前允许将多业务主次未决作为已审阅待核验结果的口径由本条替代。
- 首轮范围是全市场5,567只，逐只核验；不得把先做少量热门股当成首轮完成。优先读取同花顺单股概念解析，批量失败时改逐股；来源不可读要记录具体缺口，不能把无法读取解释成没有该业务。
- 原始资料采集、证据审查、主归属发布分别计数。采集成功不等于已核验；行业/概念名单不等于主归属结论。局部披露不足保留具体复核事项；完全缺少可审阅资料时记录未完成工作及所缺材料。
- 当前证据默认每30个自然日需要复核；到期保留旧结论供审计，但不给普通消费者继续作为已核验主归属。重新读取旧材料不能自动续期。此期限为实现默认值，可由项目所有者调整。

## 验收原则

校准样例结论正确；同类业务可用共同规则处理；证据不足和冲突不硬归类；全部股票归属消费者统一入口；二级页可搜索、筛选、查看股票和依据；历史不被改写；真实运行进程和已提供页面/API载入本次版本。

## 当前实现与接入约定

业务入口为 `tradex.smart_sector_library.SmartSectorCatalog`，输出 `smart_sector_membership.v2`；普通消费者只读取 `primary_sector_name`。`status` 只有 `verified` 才能发布归属，`unresolved/stale/disputed` 都不得发布标签作为主归属。当前归属证据在 `market_membership_evidence.v2.json`，按股票和生效日期留存；指定历史日期时不能读取未来才复核的结论。

| 消费者 | 归属读取及保护边界 |
| --- | --- |
| 每日选股、形态选股、盘中雷达与回溯表 | 当前库的单一主归属映射；原始策略档案和统计行业因子不重写 |
| 涨停池 | 新日期股票分组从库读取；2026-09-18前的不可变档案保留原方法和原版本 |
| 持仓前瞻与历史详情 | 新分析从库读取；历史详情按原分析日期读取库，独立于原档案正文与摘要哈希 |
| 复盘观察股 | 按复盘日期从库读取；所属供应商指数的观察数据不改变口径 |
| 风险偏好中的涨停领涨股 | 只按一个主归属计数；归属覆盖不全时不能以零匹配宣称板块中性 |
| 公司信息、筛选、行业比较、概念工具 | 单独的市场归属来自库；供应商板块行情、统计同业比较明确标注各自口径 |
| 聪明板块库页面 | `GET /api/smart-sector-library` 只读目录、证据和已发布研究进度；不在用户请求内联网采集 |

`stock_sector_evidence.v1` 是补充资料的中立契约：供应商原字段由 gateway 归一化，来源没有数据日期时保留缺失标志，不能把抓取时间当数据日期。采集逐只保存，可断点续跑。东方财富补充请求走项目已有共享限流，不绕过它另建请求通道。同花顺直接访问被拒绝后使用可读取的网页工具；页面编码失败时可用明确指向同一股票页面的搜索摘录，搜索结果中的其他股票不能混入该股概念。

来源研究快照 `smart_sector_research.v1` 由研究任务发布，页面只读。来源板块名称均标注未核验；其中可能包括指数、地域等供应商标签，不能直接当成业务归属。资料进度与正式核验数量分别显示。

全市场验收要求逐只审查证据并发布唯一明确归属；具体缺口属于尚未完成工作，不能计入完成验收。脚本取得5,567份材料、方法门槛校验通过或页面有5,567行，都不能独立证明这项验收完成。范围随当前股票目录更新，新增股票也须补入采集和审阅。

## 2026-09-19重要投资关联的人工复核

真实且重要的参股产业关联并非一律排除主归属。分析员在已有概念中依据市场身份比较后，可选择其为唯一主归属，但必须回查原公告确认权益/表决权和标的实际业务，显式填写relation=investment、investment_reviewed=true。阶段指被投业务的已核验阶段，必须在产业链和理由中说明投资关联，不能把被投企业销售当成上市公司并表收入。共享接口添加investment_association标记；普通调用仍只取一个主归属。未显式复核的投资、纯计划、传闻和未知产品阶段不自动通过。
