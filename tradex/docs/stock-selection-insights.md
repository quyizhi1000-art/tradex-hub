# 选股中心：相邻日对比与入档涨停回溯

适用于5个每日存档策略，盘中MACD/J扫描不受影响。结果通过现有
`/api/stock-selection/results` 的 `insights` 字段发布，契约为
`stock_selection_insights.v1`。Analysis Worker 是唯一刷新/发布所有者。
页面读取不请求行情源，不重算或覆盖历史选股结果。

## 相邻交易日对比

- 按股票代码，与**前一已验证交易日、相同策略版本**对比；不跳到更早档案。
- 版本与当前页面相同：优先注册版本，否则使用当日最高已存档版本。
- 昨日不存在、今日存在为 `new`（蓝色）；两日都存在但展示的选股证据改变为
  `changed`（橙色）。两者互斥；明细保存字段名、前值、后值。
- 当前/前日缺失或不可用为 `unknown`，禁用变化/新增筛选，避免全量误报。
  数据降级仍可对比，但明确提示可能不完整。
- 比较策略为 `displayed_selection_evidence.v2`，随分析产物发布修订。
  白名单在 `stock_selection/insights.py::STRATEGY_FIELDS` / `EVIDENCE_FIELDS`：
  多因子只比较页面显示的首条依据和风险；涨停倾向比较展示的前4条依据及前3条风险；
  长上影比较命中次数/日期及上影比例证据；放量比较本轮起点、底线、后续最低收盘、
  重置次数，以及逐次日期/涨幅/放量倍数/成交量/前5日均量；MACD/J比较信号/拐头
  日期、分组、零轴位置、间隔、J值、低位标签及逐日DIF/DEA/K/D/J证据。
- 排名、得分、因子覆盖及底层因子贡献、独立行情（最新收盘、涨幅、成交额、市值）、
  生成时间、名称、展示行业不触发变化。后台未展示的历史OHLC字段也不触发。
  证据列明确展示的价格/量能仍属于选股证据，参与比较。
- 橙色变化标记及前后明细放在证据列，新增仍在股票名称旁标蓝。
- 变化标签与行业、MACD信号分组取交集；换日期/策略重置变化筛选，同日刷新
  保留筛选，失去可比性退回全部。

## 入档涨停三级页

- 以所选存档日期为终点，含所选日共**5个已验证交易日**，不是5个有档案的日期。
- 检查该策略同版本窗口存档。股票自某次入档**当天**至所选日曾**收盘涨停**
  即纳入，即使所选当日不涨停或不在候选中也展示。
- 一只股票一行：逐次入档日期、入档收盘及可展开的完整策略数据；逐次涨停
  日期及对应的入档日期。多个入档记录完整保留，同一股票同一涨停日只计一次。
- 入档通常在收盘后，入档当天涨停是同日事实，不作为入档后的收益验证。
- 复用网关 `daily_limit_up_membership.v1`，来源元数据随证据保存。每日选股
  SQLite新增独立表 `stock_selection_limit_up_memberships`，保存标准名单及
  摘要；已成功取得的收盘名单不重复请求，合法空名单与缺失分开。
- Worker每轮最多补5个缺失日期，从最近日期向前补；失败至少间隔10分钟重试，
  当天18:00前不获取当日名单。名单摘要与展示契约版本进入发布修订。
- `missing_archive_dates`、`degraded_archive_dates`、`missing_limit_up_dates`
  披露缺失/降级，不补造股票、不用旧日期、不把未知等同无涨停。
- 行业沿用当前同花顺目录，并说明不是历史时点行业归属。
