# 双拐雷达：当前规则

2026-09-18 经确认，盘后选股和盘中雷达共同使用 `macd-j-upturn-main-board.v3`：

- 最近一次从 DIF ≤ DEA 到 DIF > DEA 的金叉发生在当天、前 1 或前 2 个交易日，且当前 DIF > DEA。金叉当天计 0，超过 2 个交易日或当前已死叉不入选。
- 当前 J 高于昨日 J；J 最近一次向上拐头发生在当天或此前 1～3 个交易日。
- 主板非 ST、有效成交与历史指标等校验保持原样。
- 盘中仍保留 DIF−DEA > 0.004、J 增量 > 0.02 的舍入保护；盘后使用正式指标。

每轮展示 **本轮符合条件的股票集合 − 上一交易日 v3 正式存档集合**。开盘第一轮已经符合的计入新增；不要求在今天更早的一轮中先被判为不符合。当天后续扫描仍与昨日固定基准比较，不减上一轮。

允许 MACD 前天已金叉、KDJ 今天才上拐的股票作为盘中新增。金叉日期仍有效的昨日候选可以与今天重叠，由差集排除。金叉年龄按核验过的交易日序列计算，不按自然日计算。

原始扫描归 Collector 保存，服务层统一投影扫描窗口和实时提示。缺少上一交易日同版本有效存档时明确显示无法判断新增；不伪造零结果，不使用旧版基准代替。有效但覆盖不足的昨日存档会附覆盖提示。收盘确认优先展示 v3 正式全量结果，旧日期仅有 v1 时显示该历史版本并标识。

v1“仅当天金叉”和 v2“不限制金叉年龄”均不再作为当前选股规则。旧存档和扫描原样保留，按自身版本核对并标识。读扫描历史的基准缓存按交易日和规则版本共同区分。

`macd_rules.recent_macd_cross_index` 统一负责盘后、盘中及候选契约验证的最近金叉判断。每只 v3 候选携带 `macd_cross_date`、`macd_cross_age_sessions`，页面展示实际金叉日期与交易日间隔；J 分组按筛选日计算，不声称 MACD 与 J 必须同日拐头。
